# VDVOЁМ НАЛЕГКЕ в Telegram

Архив для владельца игры. Он содержит сервер и полную авторскую колоду. Покупателям отправляйте ссылку на Telegram-бота. Офлайн-файл старой версии и этот архив дают доступ ко всем текстам любому получателю.

## Как выглядит покупка

Покупатель открывает бота и нажимает «Играть». Шесть карточек доступны бесплатно. Для полной игры покупатель открывает условия, подтверждает согласие и оплачивает один счёт в Telegram Stars. После подтверждения Telegram приобретённые 10 колод доступны этому аккаунту. Пара играет с одного телефона. При повторном входе покупка восстанавливается. Если подтверждение задержалось, в окне покупки есть кнопка «Проверить покупку».

## Что подготовить

- В игре уже указано имя [@VdvoemNaLegkeBOT](https://t.me/VdvoemNaLegkeBOT). Поместите токен этого бота в секреты хостинга.
- Хостинг для Node.js 24 или контейнера Docker. Нужны постоянный диск, исходящие HTTPS-запросы к Telegram и публичный адрес HTTPS для приложения. Используйте один экземпляр сервера с одной базой SQLite. Запись игры между ходами сохраняется на устройстве.
- Контакт поддержки и опубликованные условия разовой покупки. Цена полной игры — 236 Telegram Stars за один аккаунт. Ориентир для покупателя — около 500 ₽. Рублёвая стоимость зависит от способа покупки звёзд. В условиях укажите продавца, состав покупки, порядок доступа и обращения по оплате. Для новой редакции условий задайте новый URL.
- Хостинг должен направлять весь трафик на приложение. Не включайте раздачу папки проекта как статического сайта. В архиве `private/cards.json` содержит все 168 карточек.

## Настройки сервера

| Переменная | Значение |
| --- | --- |
| `APP_URL` | HTTPS-адрес приложения без дополнительного пути |
| `BOT_USERNAME` | По умолчанию `VdvoemNaLegkeBOT`. Для отдельного тестового бота укажите его имя без @ |
| `BOT_TOKEN` | Токен бота из BotFather, секрет |
| `WEBHOOK_SECRET` | Отдельная случайная строка. Для создания выполните `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` и сохраните вывод в секретах хостинга |
| `DATABASE_PATH` | Путь на постоянном диске, например `/app/data/game.sqlite` |
| `PRICE_STARS` | Цена в звёздах. По умолчанию 236 при заданных `SUPPORT_CONTACT` и `TERMS_URL`. Значение 0 закрывает новые продажи |
| `SUPPORT_CONTACT` | Ваш действующий Telegram-контакт с @ для вопросов по платежам |
| `TERMS_URL` | Публичная HTTPS-страница с условиями покупки |
| `PORT` | Порт процесса, по умолчанию 8080 |
| `TELEGRAM_TEST` | 1 для отдельного тестового окружения Telegram. Для боевого бота оставьте пустым |

## Развёртывание

1. На хостинге разместите содержимое архива. Выберите Dockerfile из корня либо Node.js 24 с командой запуска `node server.mjs`. Сторонние npm-пакеты не нужны. Для контейнера подключите постоянный диск к `/app/data`, доступный на запись пользователю `node` (UID 1000).
2. Заполните переменные. При первом развёртывании можно оставить цену равной 0 и проверить экран демо.
3. В консоли запущенного приложения однократно выполните `node bot.mjs setup`. Команда проверяет соответствие токена имени бота, настраивает webhook и кнопку «Играть». Используйте бота, выделенного для игры: эта команда подключает его входящие события и меню к новому приложению. Повторите команду после смены домена или секрета webhook.
4. Для сквозного теста оплаты используйте отдельного бота тестовой среды Telegram, отдельный домен или экземпляр и отдельную базу. Выставьте положительную тестовую цену и проверьте демо, платёж, повторное открытие и возврат с двух разных аккаунтов. На боевом сервере задайте согласованную цену, условия и поддержку. Кнопка покупки появится после перезапуска с этими настройками.
5. Сделайте резервное копирование постоянной базы с помощью SQLite backup API или штатного согласованного снимка диска. В ней хранятся покупки и возвраты. Удаление базы приводит к потере данных о доступе.

## Проверка покупок и возвраты

Покупатель может написать `/paysupport` для связи с продавцом и открыть `/terms` для просмотра условий. Для согласованного возврата найдите квитанцию в таблице `receipts` по Telegram ID покупателя, сверьте заказ и его сумму в таблице `orders`. В консоли сервера выполните `node bot.mjs refund ИДЕНТИФИКАТОР_ПЛАТЕЖА`. Команда инициирует реальный возврат звёзд. После возврата доступ по этой покупке закрывается.

## Границы защиты

Сервер проверяет подписанные Telegram данные входа, сумму, валюту, владельца заказа и подтверждение оплаты. Покупки сохраняются при повторной доставке уведомлений. Сервер проверяет доступ при каждом запросе платной карточки и ограничивает частоту загрузки. В браузер попадает содержимое открываемых карт. При показе тайной руки отдельно загружаются шесть заданий этого игрока. Ссылка на бота пригодна для рекламы и сама по себе не передаёт доступ. Покупатель всё ещё может переписать или сфотографировать показанную карточку.
